# A pointer read out of fresh memory is reported where it is read

## Context and Problem Statement

[#581](https://github.com/itsakeyfut/safec/issues/581) made a pointer read out of an allocation `malloc` or `aligned_alloc` made, before anything wrote it, `SC0411`, and only at a use that reaches memory through it: a dereference, a `free`, a `realloc`. The reason it gave was that a load or a comparison is undefined only with a trap representation (C17 6.2.6.1 p5). Review found that is narrower than the text: 7.22.3.4 p2 and 7.22.3.1 p2 leave the contents indeterminate, and Annex J.2 lists "the value of the object allocated by the malloc function is used" as undefined, which covers the load and a comparison as well. So `int *t = *box; return t == q;` built in silence ([#587](https://github.com/itsakeyfut/safec/issues/587)), where `clang --analyze` warns at the load.

The memory check carried a mark, `Held::fresh_read`, from the load to every later use of the value, through copies between locals and through fresh memory it was stored into and read back from (#588), so that the dereference or the free could be reported. This record decides where the report stands, what it says, and what the mark is for once it no longer decides a report.

#581 pinned the comparison as silent, in the case that is now `a_pointer_read_out_of_fresh_memory_and_only_compared_is_reported`, inverted.

## Decision Drivers

* Silence is the conclusion this compiler must not give wrongly. J.2 lists the load, so a rule that waits for a later use is silent about every program whose only use is one it did not list.
* Level 1 already reports a pointer local read before anything was assigned to it, "whatever the value is read for", a plain copy included. The same class of value read out of memory should not need more to be reported.
* One defect, one report. A reader handed three diagnostics for one uninitialised slot reads none of them.

## Considered Options

* **Report the read out of memory itself**, every time a value is read out of a slot nothing wrote, whatever it is read for.
* **Report each use other than a plain copy**: a comparison, an argument, a `return`, a conversion, a dereference, a free.
* **Keep #581's rule**, a use that reaches memory, and write the narrower policy into the documents.

## Decision Outcome

Chosen option: **report the read out of memory itself.**

- **Where**: at every element or terminator that reads `*l` as a value, where one dereference of `l` reaches only allocations and locals, every one of them fresh or unwritten on every path (a local since #640, below), and the value read is a pointer by its type, as `Allocations::reads_fresh` asks. An integer or a byte read out of fresh memory is a use J.2 lists too and is not followed: #581 did not follow it either, and reporting it is a decision of its own. That is an operand `Copy` of a place whose projection is exactly `Deref`, in any rvalue and in a call's arguments or a branch's condition; an `Evaluate` of such a place, since C17 6.3.2.1 p2 converts it; and any place, read or written, whose projection begins with two dereferences, since reaching through `*l` reads it. A write to `*l` is not a read of it.
- **As what**: `Unsafe`, `SC0411`, at the element's span. Fresh is an intersection over paths, so at that point the read is certain. The note keeps citing 7.22.3.1 p2, 7.22.3.4 p2 and Annex J.2.
- **A local reached by its address is memory too** (#640). A local's initial value is indeterminate (C17 6.2.4 p6, 6.7.9 p10), and the same line of Annex J.2 lists using it as undefined. That line names no condition on the address, while the normative text reaches a local whose address is taken only through a trap representation (6.2.6.1 p5); J.2 is the reading taken here, as for an allocation. Once arrays compiled (#621), every local array of pointers is one whose address is taken, and `int *q = m[0];` read an indeterminate pointer in silence. `Known::unwritten` holds, per local that may hold a pointer, whether nothing may have written it since it was made, an intersection like `fresh`, cleared by any write that may land there: an assignment to it, a store through a pointer that may point at it or one this check cannot place, a call's result, and `Known::replaced`, which is where a call or an unplaced write may have written an escaped local. `reads_fresh` asks it beside the sites, and a local whose address is taken read **by name** is the same `SC0411` (`IndeterminateLocal`). `memory::assigned` keeps the locals whose address is never taken, and `assigned::address_taken` is the one answer to which of the two asks a local. Each note cites the storage the read may reach.
- **A call writes only the locals it may reach** (#643). A call this check cannot read was taken to write every escaped local, which ADR-0029 still holds for `lost` and `foreign`, so `int **p = m; tick(); int *q = *p;` read `m` in silence. `Known::exposed_locals` holds, per local, whether code this check cannot read may hold its address: set at such a call over what it can find from its arguments, from exposed memory and from the locals already set, by the walk a load takes, which finds an address a store this check cannot place left in such memory; a union at a join, and cleared only at the local's `StorageLive`, where an address kept from the old object is indeterminate (C17 6.2.4 p2). `Known::replaced` takes it as a second answer, `may_write`, beside `may_hold`. A library copy writes only where its first argument may point, read as a call's argument is, and every escaped local where that argument is rooted in a pointer this check lost or a caller wrote. A route missed is `SC0411` about a program a call did write, which the reader sees; narrowing `lost` and `foreign` the same way was rejected, because a route missed there is a free in silence. **An argument naming no local hands none**, and that is one such route: a pointer moved off an array by arithmetic has lost its edge (#639), so `fill(&m[1] - 1)` leaves `m[0]` reported as nothing wrote it. Widening such an argument to every escaped local was rejected, because it silences every local array beside the call. **A write this check cannot pin down writes only the locals its place may land in** (#645): `Known::locals_a_write_may_land_in`, which the store door asks by the type stored and a library copy asks one dereference below its destination. That is the place's own local for an element store, the pointer's address edges, the locals the level above may be for a deeper store, and, where a level the write passes through on the way down was read out of memory, or the pointer or such a level was lost or written by code this check cannot read, every local such code may name, by the walk a call takes. Every escaped local of the type stored let one store through a pointer read out of the caller's memory clear a local array nothing could reach. The same arithmetic cost follows: `*e = &x` with `e` walked back onto `m` writes no local. **That cost is a certain report and not only an extra one**: `SC0411` is `Unsafe`, so `--allow-unknown` does not lower it and a correct program that built under that flag no longer does, and the suppression at a `free` above drops a real doubt about what the array holds once the read is reported. #647 is the change that would report such a read as `Unknown`. **A pointer itself read out of memory adds nothing to its edges** (#648). Those name what the memory it was read from was recorded to hold as it was read, and what such code names by the time of the write includes locals whose address left only after the read: `t = *pp; *b = m; *t = 0;` was taken to write `m`, and an indeterminate `m[0]` built in silence. A level the write reads its way through is read at the write, and a lost or foreign pointer carries no edge for what it may be, so those keep the walk. What the edges miss is now `SC0411` about a local the write did assign, which the reader sees, rather than a silence; none is known, since an address a call was handed is a write of that local at the call and a store records what it stores. Carrying, on each pointer read out of memory, what such code could name as it was read was measured and rejected: it decided no case and cost 14 to 17% more peak memory, release build.
- **Nothing more is said at a later use of the value.** A dereference, a `free` or a `realloc` of it is not reported as `SC0411` again, because the read that made it was.
- **A store of the value back into fresh memory writes the slot**, as any store does. #588 kept such a slot fresh, so that reading it back was reported; with the report at the first read that is a second report of one defect, and it reported the copy the lowering takes of an assignment's value (C17 6.5.16 p3) as "read before anything wrote it" at the store that wrote it. Found while implementing.
- **The mark stays, and only suppresses.** `Held::fresh_read`, its propagation through copies, and the `escaped` clause of `Known::holds_fresh_read` remain. They decide no report. They decide one suppression: every doubt this check would raise at a `free` or `realloc` about the local it is handed is dropped, where that local is known to hold a value read out of fresh memory and so reported at that read. Such a value names no allocation, so the doubt is that this check knows none, the same defect again. Only a doubt is dropped, never a proof, and only for the local the free is handed.
- **A free leaves a site fresh.** Clearing it at a `free` or `realloc` was tried, so that a read out of freed memory would be only the use after free `SC0402` reports, and review found it silent: `fresh` is an intersection nothing sets again, a `realloc` that fails leaves the old block live and unwritten (C17 7.22.3.5 p4), and a free of one of two allocations leaves the other. So a read out of a block nothing wrote before it was freed is reported twice, `SC0411` beside `SC0402`, and both are true of it. The two are said under different keys, so neither replaces the other.

Reporting each use other than a copy was rejected because its failure is silence: every position the list misses is a use J.2 makes undefined that builds, and an argument is one it cannot reach without a summary of what the callee does ([#596](https://github.com/itsakeyfut/safec/issues/596)). Keeping #581's rule was rejected for the same failure at a known place, the comparison. The chosen option's failure is a report about a program that reads a slot and throws the value away, which the reader can see and fix by writing the slot first.

Keeping #588's rule for a store, with a second per-site bit saying the slot holds a value already reported, was rejected: it would carry the suppression through the store as well, at the price of a lattice field whose error drops a doubt that should stand, which is a silence. Without it, freeing a pointer read back out of such a slot raises a doubt beside the report, which the reader can see.

Dropping the mark along with the reports it used to make was rejected because a free of a value read out of fresh memory then raises a second diagnostic, a doubt saying this check knows no allocation the value names, beside the proof at the read. The mark is the only thing that knows the two are one defect.

### Confirmation

Each in `tests/cases/memory/` unless named otherwise, with the mutation that fails it in its comment in `tests/cases.rs`:

* **The read is reported, whatever it is read for.** `a_pointer_read_out_of_fresh_memory_and_only_compared_is_reported` and `a_pointer_read_out_of_fresh_memory_and_discarded_is_reported`: drop the call to `loaded_indeterminate` for an element, and both build. `..._in_a_comparison_is_reported`, `..._under_a_logical_not_is_reported`, `..._and_handed_to_a_call_is_reported`, `..._by_an_expression_statement_is_reported`, `..._through_two_dereferences_is_reported` and `..._by_a_condition_is_reported` each fail when the matching arm of `read_out_of_memory_in_element` or `read_out_of_memory_in_terminator` reads nothing. `a_pointer_written_into_fresh_memory_is_not_reported` fails when a write through one dereference is read as a read.
* **Not again at a later use.** `a_pointer_read_out_of_fresh_memory_read_through_and_freed_is_reported_once`: report a read through a local `Known::holds_fresh_read` marks, and `SC0411` joins at the read through.
* **The suppression at a free.** `..._and_freed_is_reported_once` fails when the suppression is dropped, `..._and_reallocated_is_reported_once` when it is asked of `free` alone, and `a_copy_of_a_pointer_read_out_of_fresh_memory_freed_is_reported_once` when a plain copy clears the mark.
* **What the suppression must not drop.** `..._a_call_may_have_replaced_is_still_doubted_where_it_is_freed` and `..._a_call_replaced_is_still_doubted_where_a_copy_is_freed` fail when the `escaped` clause is dropped, and `..._on_one_arm_only_is_still_doubted_where_it_is_freed` when the mark is joined with `||`.
* **A store writes the slot.** `..._stored_and_read_back_is_reported_once`: keep the slot fresh for a store of an indeterminate pointer, and `SC0411` joins at the store and at the read back.
* **A local reached by its address** (#640). `a_pointer_read_out_of_a_local_array_nothing_wrote_is_reported` and `a_pointer_read_through_the_address_of_a_local_nothing_wrote_is_reported` build when `reads_fresh` asks the sites alone; `a_local_whose_address_is_taken_read_by_name_before_anything_wrote_it_is_reported` builds when nothing is reported by name; the cases beside them in `tests/cases.rs` name the mutation of each door that clears a local.
* **A call writes only the locals it may reach** (#643). `a_pointer_read_out_of_a_local_array_an_unrelated_call_did_not_reach_is_reported` and `a_pointer_read_out_of_a_local_array_a_copy_elsewhere_did_not_write_is_reported` build when an opaque call or a library copy writes every escaped local again; the `..._is_not_reported_as_indeterminate` cases beside them in `tests/cases.rs` name the mutation of each route the walk takes. `a_pointer_read_out_of_a_local_array_made_again_after_a_call_kept_the_old_one_is_reported` builds when `StorageLive` leaves the bit alone, and `a_local_array_handed_to_a_call_through_a_pointer_moved_back_onto_it_is_reported` is the false report kept on purpose: it loses its `SC0411` when an argument naming no local writes every escaped local. `a_pointer_read_out_of_a_local_array_a_store_through_caller_memory_did_not_write_is_reported` and `..._a_copy_through_caller_memory_did_not_write_is_reported` build when such a store or copy writes every escaped local again (#645), and `a_local_array_filled_backwards_through_a_moved_pointer_is_reported` and `a_double_free_through_an_array_filled_backwards_is_reported_as_a_read_nothing_wrote` are the store's false report kept on purpose and what it costs. `a_pointer_read_out_of_a_local_array_a_copy_through_a_dereference_of_a_placed_pointer_did_not_write_is_reported` builds when the depth of a write rather than the levels it passes through decides whether unknown code may name what it lands in, and `a_pointer_read_out_of_a_local_array_an_int_stored_where_it_may_point_did_not_write_is_reported` when the store door drops the type from what it wrote. `a_pointer_read_out_of_memory_before_a_local_array_left_does_not_write_it` and its library-copy form build when a pointer read out of memory lands in every local such code names at the write again, and `a_pointer_read_out_of_memory_after_a_local_array_left_may_write_it` and `..._before_a_local_array_left_on_one_path_only_may_write_it` gain `SC0411` when such a pointer lands in none of its edges (#648).
* **A free leaves a site fresh.** `a_pointer_read_out_of_the_old_block_after_a_failed_realloc_is_reported` builds when a `realloc` clears what it is handed, and `a_pointer_read_out_of_fresh_memory_a_free_may_have_freed_is_still_proved` loses its proof when a free clears what it may free. `returns/a_pointer_read_out_of_a_freed_table_and_returned` loses its `SC0402` when the report at the read is keyed by `*l` rather than by `l`.

### Consequences

* Bad, because a pointer read back out of a slot it was stored into, and then freed, raises a doubt beside the report at the first read.
* Good, because the first use J.2 lists is the one reported, so no later use can be silent for want of being listed, and the program in #596 is reported at its load without a callee summary.
* Good, because the rule is level 1's for an unassigned local, which reports a plain copy too, and `clang --analyze` warns on the same programs, though not on an expression statement `*box;` alone, which this reports, and not at the same column.
* Bad, because a program that reads an unwritten slot and discards the value is refused, which C17's normative text makes undefined only where the bits read are a trap representation (6.2.6.1 p5). Annex J.2, which is informative, is the reading taken here.
* Bad, because the mark is kept for a suppression alone, which looks redundant beside a report that no longer reads it. This record is why it is not.
* What would reverse this: a target or a reading of C17 under which reading an indeterminate pointer is defined, which would move the report back to the uses that reach memory.
